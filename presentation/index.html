Architecture · lineage and reliability · 5 min

Replayable, traceable, all-or-nothing

  • Raw is immutable: each fetch = a dated folder with payload.json + metadata.json (URL, time, SHA-256); latest.json points to the one to use (D-48)
  • Offline by default: the committed snapshots give reviewers identical numbers; --refresh fetches (D-66, D-68)
  • Resilient ingestion: timeouts + 3 retries; a failed fetch falls back to the last good snapshot and is marked stale; no data at all stops the run (D-47)
  • All-or-nothing: build in data/.tmp/<run_id>, publish only if every step succeeds; a failed run leaves the dashboard untouched
  • Lineage: _build.json per layer (run id, inputs, outputs, checksums); every HR row keeps its CSV line number
  • Contracts: every table passes a schema check before it is written; an unknown code stops the run with "add a mapping row"

Architecture · temporal alignment · 5 min

No future information: the "newspaper rule"

  • Each cohort has an as-of date: the start of its hire quarter (turnover: start of its 12-month window) (D-28, D-38)
  • A value is usable from period end + lag; lags measured from the APIs and rounded up: monthly +2, quarterly +3, annual +7 months (D-29, D-58)
  • ASOF join: the newest value already usable on the as-of date
  • Annual GDP carried forward with its own period, frequency and age, never as new quarterly values (D-31)

Limitation: APIs return today's revised values, not historical vintages.

Trade-offs · 3 min

Deliberate cuts and known limitations

Chosen and why

  • Plain HTML + small API over Streamlit / static JSON: literal "HTML", testable service boundary (D-04, D-05)
  • DuckDB on Parquet: real SQL, no server, reviewer-friendly (D-03, D-41)
  • As known at hire over conditions during the window: no hindsight (D-28)
  • Descriptive + rank tests over regression / survival models: small, dependent samples
  • No CI in the timebox; tests run locally (D-64)

Limitations

  • Population = hires since 2020; early-2021 turnover is a ramp-up effect (D-23)
  • Unconfirmed assumptions (senior, Sr Mgmt, 90-day exits), each shown not to change a verdict
  • Fixed-lag approximations; revised values, no vintages (D-58)
  • 7–29 hires per country-quarter; rows unweighted (D-80)
  • HICP dataset discontinued (successor documented); Irish GDP distorted
